# mk-mock-reports

Independent Math Kangaroo mock exam reports and report lookup. Separate from the geometry challenge reports.

## Score ranks

Place ranks distinct scores within the same test Level, combining all school grades. Equal scores share a place, and the next lower score takes the next place. For example, 90, 90, 86, 86, 82 points receive places 1, 1, 2, 2, 3.

Percentile remains the percentage of students in the same Level who scored strictly lower. Score ranks and percentiles measure different things.

The current release preserves all existing report URLs, comments, enrollment-specific content, and the independent Mock 1 report-open/button-click analytics.
